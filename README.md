# Trabenium

Trabenium is an optimization addon built specifically to provide **Sodium compatibility** for the **Trabe** mod ecosystem. It bridges the gap between engine-level rendering optimizations and Trabe's custom mechanics, ensuring smooth performance without graphical glitches.

## 🚀 Features

* **Sodium Compatibility:** Resolves rendering conflicts, crashes, and visual bugs when running Trabe mods alongside Sodium.
* **Performance Boosts:** Optimizes custom chunk rendering and entity overlays introduced by the Trabe ecosystem.
* **Seamless Integration:** Works out of the box with zero configuration required—just drop it into your mods folder.

## 📦 Installation

1. Make sure you have your preferred **Mod Loader** installed (Fabric/NeoForge).
2. Download and install **Sodium**.
3. Download the core **Traben** mods.
4. Place **Trabenium** into your `.minecraft/mods` directory.
5. Launch the game and enjoy optimized performance!

## 🧩 Dependencies

* Minecraft (Supported versions)
* Fabric API / NeoForge (As applicable)
* Sodium
* Trabe Base Mod(s)
