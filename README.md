# Trabenium Mod for Minecraft

**Trabenium** is a performance-focused Minecraft optimization mod designed to bridge compatibility between **Sodium** and **Trabe Mods**. It ensures seamless rendering, fixes graphical conflicts, and unlocks maximum frame rates when running these environments together.

---

## 🚀 Features

* **Seamless Integration:** Eliminates rendering pipelines clashes between Sodium and Trabe engine components.
* **Performance Boosts:** Optimizes memory usage and reduces micro-stutters when loading custom Trabe world geometry.
* **Graphic Fixes:** Corrects broken textures, translucent block sorting issues, and vertex light mapping errors.

---

## 🛠️ Installation

### Prerequisites
Make sure you have the following installed before adding Trabenium:
1. **Minecraft** (Supported versions listed in releases)
2. **Fabric Loader** or **NeoForge/Forge** (Depending on the specific build)
3. **Sodium Mod**
4. **Trabe Mods** core packages

### Step-by-Step Setup
1. Download the latest version of Trabenium from the releases page.
2. Drop the downloaded `.jar` file into your Minecraft `mods` folder.
3. Launch your game through your modded profile launcher.

---

## ⚙️ Configuration

Trabenium works automatically out of the box. However, you can tweak advanced performance metrics directly inside the standard Sodium Video Settings menu. A new "Trabenium Compatibility" tab will appear containing toggles for specific rendering patches.
